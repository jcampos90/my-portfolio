# Unverifiable CV claims are deliberate

The CV states that cross-platform mobile applications were deployed via React Native for iOS and Android, and that the Google AI Professional Certificate produced a portfolio of 20+ AI-generated artifacts plus a custom AI solution. None of that work exists in any repository on this machine, and none of it is publicly linkable. We reproduce those claims on the Portfolio anyway and feature only demonstrable repositories as evidence, rather than deleting the claims or manufacturing artifacts to satisfy them.

## Consequences

- A visitor cannot verify the mobile or AI-artifact claims by clicking anything. This is a deliberate trade-off: the owner asserts the work is real, and dropping it would misrepresent real experience.
- Do not "fix" this by removing the claims. If they are ever contradicted by evidence, that is a decision for the owner, not for a later editor.
- Project write-ups are reserved for linkable work, so the page never mixes proof and assertion in the same breath.
